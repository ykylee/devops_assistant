# 과제 발의 계획서

- Document Version: `v0.1.0`
- Project Version: `v0.0.1`
- Last Updated: `2026-03-12`

## 1. 과제명

프로젝트 진행 현황 및 KPI 통합 관리 웹 구축

## 2. 추진 배경

여러 프로젝트의 진행 상태, 테스트 결과, 소스코드 품질, 개인 업무 현황, 경고 및 알림을 각각 분산된 방식으로 확인하면 관리 효율이 떨어지고 우선순위 판단이 늦어질 수 있다. 이를 해결하기 위해 프로젝트 관리에 필요한 핵심 정보를 한 화면과 일관된 탐색 구조로 통합 제공하는 웹 기반 대시보드 구축이 필요하다.

## 3. 목표

- 프로젝트 진행 현황을 한눈에 파악할 수 있는 통합 웹 대시보드를 구축한다.
- 프로젝트별 현황 탭에서 KPI 12개 항목을 효과적으로 확인할 수 있도록 한다.
- 테스트 현황 탭에서 테스트 관련 지표 7종을 제공한다.
- 소스코드 품질 탭에서 품질 관련 지표 4종을 제공한다.
- 프로젝트 목록, 프로젝트 상세 화면, 검색, 필터 기능을 통해 원하는 프로젝트를 빠르게 찾고 분석할 수 있도록 한다.
- 사용자별 할 일과 경고/알림을 함께 제공하여 운영 대응 속도를 높인다.

## 4. 기대 효과

- 프로젝트 현황, 테스트 상태, 품질 상태를 통합적으로 관리할 수 있다.
- KPI 기반의 빠른 현황 판단이 가능해져 의사결정 속도를 높일 수 있다.
- 테스트 및 품질 이슈를 조기에 식별해 대응 리스크를 줄일 수 있다.
- 검색과 필터를 통한 탐색 편의성 향상으로 업무 효율을 높일 수 있다.
- 개인 할 일과 경고/알림을 한 화면에서 확인함으로써 실행 우선순위 정리가 쉬워진다.

## 5. 주요 기능 방향

### 5.1 메인 대시보드

- 프로젝트 요약, 프로젝트별 현황, 테스트 현황, 소스코드 품질을 탭으로 제공
- 사용자 할 일 요약 제공
- 경고 및 알림 표시 제공

### 5.2 KPI 및 지표 관리

- 프로젝트별 현황 탭에 KPI 12개 항목 배치
- 테스트 현황 탭에 테스트 지표 7종 배치
- 소스코드 품질 탭에 품질 지표 4종 배치
- 추후 지표 상세 정의와 drill-down 확장 가능 구조 확보

### 5.3 탐색 및 검색

- 상단 네비게이션 바를 통한 메뉴 이동
- 프로젝트 검색창 제공
- 프로젝트 목록 화면 제공
- 프로젝트 상세 페이지 제공
- 시계열 및 조직 기준 필터 제공

## 6. 개발 예정 내용

### 6.1 화면 개발 범위

- 메인 대시보드 화면
- 프로젝트 목록 화면
- 프로젝트 상세 화면
- 탭 기반 현황 화면 구성
- 검색 및 필터 UI 구성

### 6.2 기능 개발 범위

- KPI/테스트/품질 지표 표시 로직 연계 구조 설계
- 프로젝트 검색 및 상세 이동 기능
- 시계열 필터와 조직 필터 적용 구조
- 사용자별 할 일 요약 기능
- 경고 및 알림 표시 기능

### 6.3 문서화 및 관리 범위

- 요구사항 문서 고도화
- 설계 문서 작성
- 스케치 및 화면 구체화
- 테스트 기준 및 리포트 체계 정리

## 7. 확장성

- KPI 12개 항목의 상세 정의가 확정되면 지표별 drill-down 화면으로 확장 가능하다.
- 테스트 지표 7종과 품질 지표 4종은 이후 세부 지표 추가에 대응할 수 있도록 확장 가능 구조로 설계할 수 있다.
- 프로젝트 상세 화면은 차트, 추이 분석, 이력 관리 기능으로 확장 가능하다.
- 필터 구조는 현재 시계열과 조직 기준 외에도 담당자, 상태, 우선순위 등의 조건으로 확장 가능하다.
- 향후 외부 시스템 연계를 통해 자동 수집 기반의 운영 대시보드로 발전시킬 수 있다.

## 8. 추진 전략

- 1단계: 요구사항 및 화면 구조 정립
- 2단계: 기초 설계 및 정보 구조 정의
- 3단계: 메인 화면, 목록 화면, 상세 화면 구현
- 4단계: 지표 표시, 검색, 필터, 알림 기능 구현
- 5단계: 테스트 및 운영 안정화

## 9. 결론

본 과제는 프로젝트 운영 관리에 필요한 핵심 정보를 통합해 보여주는 관리형 웹 구축을 목표로 한다. KPI, 테스트, 품질, 업무, 경고 정보를 일관된 화면 구조 안에서 제공함으로써 운영 효율과 의사결정 품질을 높일 수 있으며, 향후 세부 지표와 연계 기능을 지속적으로 확장할 수 있는 기반이 될 것이다.
