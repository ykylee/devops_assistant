## 1. 문서 목적

본 문서는 프로젝트 진행 상황과 KPI 지표를 한눈에 관리할 수 있는 웹 시스템의 소프트웨어 요구사항을 정의한다. 현재 단계에서는 메인 페이지 중심의 화면 요구와 사용자 관점의 기능 요구를 구체화하며, 프로젝트 목록 탐색, 프로젝트 상세 이동, 상단 검색, 시계열 및 조직 필터 구조를 포함한다. KPI는 총 12개 항목이며 프로젝트별 현황 탭에서 높은 시인성으로 제공하는 것을 전제로 한다. 테스트 현황 탭은 7종 지표, 소스코드 품질 탭은 4종 지표를 제공하며, 세부 지표 정의는 추후 별도 요구사항으로 확장한다.

## 2. 시스템 개요

본 시스템은 여러 프로젝트의 진행 상황을 통합적으로 확인할 수 있는 웹 기반 대시보드이다. 사용자는 메인 페이지에서 전체 프로젝트 요약, 프로젝트별 현황, 테스트 현황, 소스코드 품질 현황, 개인 할 일, 경고 및 알림을 확인할 수 있어야 하며, 프로젝트 목록 화면과 검색 기능을 통해 개별 프로젝트 상세 페이지로 이동할 수 있어야 한다. KPI 12개 항목은 프로젝트별 현황 탭에, 테스트 7종 지표는 테스트 현황 탭에, 품질 4종 지표는 소스코드 품질 탭에 배치된다.

## 4. 전제 및 범위

### 4.1 전제

- 사용자는 시스템에 접속하여 본인 기준의 화면을 확인할 수 있다고 가정한다.
- 시스템은 여러 프로젝트의 진행 상태 정보를 수집하거나 제공받을 수 있다고 가정한다.
- KPI 12개 항목, 테스트 7종 지표, 소스코드 품질 4종 지표의 세부 정의는 현재 범위에 포함하지 않는다.

### 4.2 현재 범위

- 메인 페이지 대시보드 요구사항 정의
- KPI 12개 항목 표시 요구사항 정의
- 테스트 7종 지표 표시 요구사항 정의
- 소스코드 품질 4종 지표 표시 요구사항 정의
- 프로젝트 목록 화면 요구사항 정의
- 프로젝트 상세 페이지 진입 요구사항 정의
- 상단 네비게이션 및 프로젝트 검색 요구사항 정의
- 탭 기반 현황 전환 요구 정의
- 시계열/조직 필터 요구 정의
- 사용자별 할 일 요약 요구 정의
- 경고 및 알림 표시 요구 정의

### 4.3 제외 범위

- KPI 12개 항목의 명칭, 계산식, 임계값 정의
- 테스트 7종 지표의 명칭, 계산식, 임계값 정의
- 소스코드 품질 4종 지표의 명칭, 계산식, 임계값 정의
- 검색 정렬 및 자동완성 세부 로직 정의
- 필터 간 종속 규칙 및 기본값 정의
- 외부 시스템 연동 방식 정의
- 데이터베이스 및 내부 아키텍처 설계
- 화면별 세부 UI 스타일 설계

## 7. 화면 요구사항

### 7.1 메인 페이지 구성

메인 페이지는 다음 영역으로 구성되어야 한다.

1. 상단 헤더 영역
2. 상단 검색 영역
3. 시계열 필터 영역
4. 조직 필터 영역
5. 현황 탭 영역
6. 탭 선택에 따라 변경되는 메인 현황 콘텐츠 영역
7. 사용자 할 일 요약 영역
8. 경고 및 알림 영역
9. 향후 KPI 및 품질 확장 영역

### 7.2 프로젝트 목록 화면 구성

프로젝트 목록 화면은 다음 영역으로 구성되어야 한다.

1. 상단 네비게이션 바
2. 프로젝트 검색 영역
3. 시계열 필터 영역
4. 조직 필터 영역
5. 프로젝트 목록 테이블 또는 카드 영역
6. 프로젝트 상세 페이지 진입 링크

### 7.3 프로젝트 상세 화면 구성

프로젝트 상세 화면은 다음 영역으로 구성되어야 한다.

1. 프로젝트 기본 정보 영역
2. 프로젝트 진행 현황 요약 영역
3. 테스트 현황 영역
4. 소스코드 품질 영역
5. 관련 경고 및 알림 영역

## 8. 사용자 시나리오

### 8.1 관리자 시나리오

1. 관리자는 메인 페이지에 접속한다.
2. 상단 네비게이션 바와 필터 영역을 확인한다.
3. 시계열 필터와 조직 필터를 조정해 조회 범위를 좁힌다.
4. 프로젝트별 현황 탭에서 KPI 12개 항목을 확인한다.
5. 테스트 현황 탭에서 테스트 지표 7종을 확인한다.
6. 소스코드 품질 탭에서 품질 지표 4종을 확인한다.
7. 경고 및 알림을 확인하여 우선 대응이 필요한 항목을 식별한다.

### 8.2 일반 사용자 시나리오

1. 사용자는 메인 페이지에 접속한다.
2. 상단 검색창에서 프로젝트명을 입력한다.
3. 검색 결과를 선택해 프로젝트 상세 페이지로 이동한다.
4. 본인에게 할당된 할 일 요약을 확인한다.
5. 관련 프로젝트의 현재 상태, 테스트 현황, 소스코드 품질 현황을 탭 또는 상세 화면에서 확인한다.
6. 본인과 연관된 경고 또는 알림을 확인한다.

### 8.3 프로젝트 탐색 시나리오

1. 사용자는 프로젝트 목록 화면으로 이동한다.
2. 시계열 필터에서 `년도`, `월`을 선택한다.
3. 조직 필터에서 `팀`, `그룹`, `파트`를 선택한다.
4. 목록에서 원하는 프로젝트를 찾는다.
5. 프로젝트 항목을 선택해 상세 페이지로 이동한다.
